# Keyboard shortcuts

Choose **Help** > **Keyboard Shortcuts** to see every key in its own window. Press ⎋ (Escape) to close it.

## Search window

Press ↓ in the search field to move into the results. Press ↑ on the first row to go back to the field.

| Keys | What it does |
|---|---|
| ↑ ↓ | Move through the results |
| ↩ | Open the selected file, or the first row when nothing is selected |
| ↩ in **File content:** | Make a term, or start Search Content when the field has no text left |
| ⌘↩ | Show the selected file in Finder |
| Space | Show or close Quick Look (in a text field, Space types a space) |
| ⌘C | Copy the path of the selected file |
| ⌘↓ | Show the contents of the selected archive |
| ⎋ | Clear the search text, then the filters |
| ⌘N | Open a new window |
| ⌥⌘I | Show or hide the inspector |
| ⇧⌘. | Hide or show invisible files |
| ⌘, | Open Settings |
| ⌘Q | Quit Wherever |

The first ⎋ clears the text. The second ⎋ clears **Search folder**, sets **File name match** back to **Contains** and resets the pills. **Hide Invisible Files** keeps its setting.

## Wherever search

Wherever search is the [launcher](launcher.md), the panel that opens over any app. ⌃⇧F is its default key. You can change it in **Settings…** > **General**. The Keyboard Shortcuts window then shows your key, or `–` if you removed it.

| Keys | What it does |
|---|---|
| ⌃⇧F | Open or close Wherever search |
| ↑ ↓ | Move through the results |
| ↩ | Open the selected file and close Wherever search |
| ⌘↩ | Show the selected file in Finder and close Wherever search |
| Space | Show or close the preview |
| ⌘C | Copy the path of the selected file |
| ⌘↓ | Show the contents of the selected archive in Wherever |
| ⌘N | Show all results in a Wherever window |
| ⎋ | Clear the search text, then close Wherever search |
| ⌘W | Close Wherever search |

⌘C leaves the panel open. Clicking another window or app closes the panel.

## Archive window

[Archives](archives.md) explains what each key does.

| Keys | What it does |
|---|---|
| ↩ ⌘↓ | Open the item, the folder or the archive |
| ⌘↑ | Go to the enclosing folder |
| Space | Show or close Quick Look |
| ⌘↩ | Show the archive in Finder |
| ⌘C | Copy the path inside the archive |
| ⎋ | Clear the search text |
| ⌫ | Delete the selected items |
| ⌘S | Save the changes |
| ⇧⌘S | Save the archive under a new name |
| ⌘Z | Undo the last change |
| ⇧⌘Z | Redo the last change |

## Menu keys

| Item | Keys |
|---|---|
| **New Window** | ⌘N |
| **Settings…** | ⌘, |
| **Quit Wherever** | ⌘Q |
| **Show Inspector** or **Hide Inspector** | ⌥⌘I |
| **Hide Invisible Files** | ⇧⌘. |

⌘Q quits Wherever. The menu bar icon and the launcher shortcut stay.
