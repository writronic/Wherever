# Wherever documentation

These pages show how to use Wherever and how to build it. The [project overview](../README.md) has the short version.

## Using Wherever

- [Getting started](getting-started.md): install Wherever, turn on Full Disk Access, and run your first search.
- [Searching](searching.md): type a name, find it despite an accent or a typo, and read how results rank.
- [Search syntax](search-syntax.md): narrow results with words, signs and filters.
- [Results, inspector and status bar](results.md): choose columns, sort, open a result, and read the status bar.
- [Normal mode](normal-mode.md): pick a folder, filter results, and search inside files.
- [Archives](archives.md): look inside a zip, tarball, RAR, pkg or dmg, and edit a zip or tarball.
- [The launcher](launcher.md): search from any app with ⌃⇧F and open a file.
- [The command-line tool](command-line.md): install the `wherever` command and search from Terminal.
- [Disks and excluded paths](disks-and-locations.md): index another disk and skip paths.
- [Settings](settings.md): change startup, appearance and shortcut, and back up or reset.
- [Keyboard shortcuts](keyboard-shortcuts.md): find the key for a menu or search action.
- [Troubleshooting and FAQ](troubleshooting.md): look up a message and fix it.
- [Your data on this Mac](privacy-and-data.md): see what Wherever stores and how to remove it. Read the [privacy policy](../PRIVACY.md) for a short summary.

## Building Wherever
