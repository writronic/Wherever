# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in Wherever, report it privately. **Do not open a public issue or pull request.**

- **Email:** [contact@writronic.com](mailto:contact@writronic.com)
- **GitHub:** [Report a vulnerability](https://github.com/writronic/Wherever/security/advisories/new) through private vulnerability reporting

Please include:
- A description of the vulnerability
- Steps to reproduce
- Affected version(s)

## Supported Versions

Only the latest release gets security fixes.

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |
| Older   | ❌        |

## Disclosure Process

1. We acknowledge your report within **7 days**.
2. We investigate and work on a fix privately.
3. We publish a patched release and describe the vulnerability in the release notes.

Please give us a reasonable time to fix the issue before you disclose it in public.
